# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

库房修复跟进：片段可登记为待修、已修复或跳过。待修与跳过片段保留放映顺序但不计入总时长；登记已修复时颜色恢复为正常、修复方式必填，原本的偏移和破损继续留档；统计区单列待修与跳过数量。

业务代码分三层维护：

- `rules.js`：判定规则（修复登记校验、时长统计口径、试映前提醒）
- `store.js`：清单保存（本地读写、默认数据、旧清单字段补全）
- `app.js`：页面交互（渲染与事件）

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
