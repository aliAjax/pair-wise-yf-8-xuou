# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移，并跟进库房修复结果。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 修复跟进

- 片段可登记为**待修**、**已修复**或**跳过**（默认为未登记）。
- **跳过**项保留放映顺序，但不计入总时长；清除跳过登记后恢复计时。
- 登记**已修复**时必须填写修复方式；登记后颜色恢复为“正常”，原本的偏移和破损情况继续留档，片段恢复试映统计（不再列入破损与试映前核对）。
- 统计区单列待修数量与跳过数量；导出清单同样带修复状态、留档信息和跳过标记。

## 代码结构

业务代码按职责分为三份，`index.html` 依次加载：

- `rules.js` — 判定规则：修复状态流转与必填校验、时长口径（跳过不计入）、统计与试映前核对项。
- `store.js` — 清单保存：本地存储读写、旧数据修复字段补全、导出清单文本。
- `app.js` — 页面交互：DOM 渲染与事件绑定。
